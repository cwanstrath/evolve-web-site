O QUE FUNCIONA

- Vídeos locais.
- Carrinho com localStorage.
- Alteração de quantidade.
- Checkout demonstrativo.
- Geração de número de pedido.
- Nenhum CPF ou chave Pix está presente no código.

PAGAMENTO REAL
O pacote NÃO processa dinheiro real. Para isso, use um gateway de pagamento e um backend.
Nunca coloque CPF, token secreto, chave privada ou credenciais de gateway no HTML/JavaScript público.
Em um projeto real, a conta de pagamentos deve estar regularizada e ser operada pelo responsável legal adequado.
